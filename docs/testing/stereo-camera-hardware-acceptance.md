# Stereo Camera Windows-x64 验收清单

此清单只用于连接真实设备的 Windows x64 环境；自动化 fake-camera 测试不等同于硬件验收。

## 前置条件

- [ ] Windows x64，已安装 .NET 8 WindowsDesktop SDK。
- [ ] 插件包由 StageStereoCameraPlugin 生成，lib 中包含 SDK 清单文件和许可证目录。
- [ ] 相机与主机网络连通，使用四段点分十进制 IPv4 地址。
- [ ] 不使用 StereoCamera.Net.dll、vendor NLog.dll 或系统级 PATH/注册表安装。

## 硬件验收

- [ ] 通过 IP 连接相机，彩色、深度和两路标定输出均出现。
- [ ] 执行一次运行后观察到一帧结果，并确认停止、断开、设备句柄和运行时作用域均回收。
- [ ] 让下游节点故意变慢持续运行，确认回调不重叠且算法拿到的是最新帧，不消费旧缓存。
- [ ] 确认四个输出的帧 ID、图像内嵌标定引用和独立标定槽对应一致。
- [ ] 点击停止后再次运行，确认相机只建立一个新的生命周期且可以重复使用。
- [ ] 运行中拔掉相机，确认最新帧 mailbox fault、界面报告错误且清理完成，不自动重连。
- [ ] 持续运行时关闭窗口，确认窗口等待停止完成后退出，没有后台采集线程或句柄残留。

硬件不可用时，以上硬件项目保持未勾选，不把自动化测试结果记为硬件通过。
